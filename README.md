# e-plantShopping

Paradise Nursery plant shopping application built with React, Vite, Redux Toolkit, and React Router.

## Features
- Landing page headed “Welcome To Paradise Nursery” with a Get Started button
- About Us page
- Three categories with six unique houseplants each
- Product thumbnails, names, descriptions, and prices
- Redux cart reducers: `addItem`, `removeItem`, and `updateQuantity`
- Dynamic cart count, quantity controls, item totals, and cart total
- Checkout “Coming Soon” alert and Continue Shopping link

## Run locally
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.
